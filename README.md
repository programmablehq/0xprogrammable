# Programmable archive

This repository preserves the former Programmable organization profile and its assets. The maintained organization is [programmablehq](https://github.com/programmablehq), and the current product source is [PROGRAMMABLE](https://github.com/programmablehq/PROGRAMMABLE).

Programmable provides Module Mode coin launches and Custom Launch APIs on Robinhood Chain, with separate Ethereum launch references. Use the current documentation for supported contract layouts, fees, API clients and deployment information.

| --- | --- |
| Launch a coin | [Create](https://programmable.market/launch) |
| Launch custom token and hook contracts | [API quickstart](https://programmable.market/docs/developers/custom-launch-quickstart) |
| Read the product documentation | [Programmable docs](https://programmable.market/docs) |
| Integrate launch records | [Developers](https://github.com/programmablehq/Developers) |
